Windows PowerShell Quick Start

Phase 1 Commands

Run these commands in Windows PowerShell from the c:\TradeMind workspace:

Windows PowerShell 
# 1. Create and activate virtual environment
py -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run automated tests
pytest

# 4. Start TradeMind development server
python run.py
